# REUNIR production roadmap

Updated 24 September 2026. Product scope and deployment status are separate.

## Alpha 01: preserved foundation

Community/learning/doing loop, shared rules, real auth/API/PostgreSQL implementation, private spaces, preview and test evidence. Original source and migration retained.

## Alpha 02: purpose and evidence, delivered locally

Purpose-led Home; explicit Become/Build/Achieve purposes; paths over existing lessons/missions/projects; evidence-derived milestones; private member goals; recognised project contributions; reviewed outcomes; member-visible community outputs; proof-oriented profile additions and a resource view. Additive schema, permissions, upgrade tests and regression checks. No live cloud deployment implied.

## Next: connected invitation-only pilot

Connect the dedicated Neon/Vercel staging environment, provision the owner's empty community, apply migrations with a separate credential, verify restricted-role pooling and cookie sessions on a real origin, and rehearse restore. Add dependable invitations, email verification/recovery, member suspension/removal, administrative safeguards and deployment CI against actual PostgreSQL. Replace fiction with approved Code Black content. Keep private goals private and validate evidence-source access end to end.

## Next everyday product work

Private messaging with explicit membership/blocking boundaries and reporting; notification delivery/preferences; moderation review lifecycle and appeals; course editing/reordering; content-linked attachments; evidence review/revocation history. Implement a small tested experience rather than decorative chat or activity counters. These ordinary operations take precedence over AI or a marketplace.

Move broad workspace reads to cursor-paginated domain endpoints before scaling beyond the disclosed pilot bounds. Add stable read models and transactional outbox delivery/retry, retention and export/deletion. Introduce another service only when this workload justifies it.

## Creator operations

Scoped instructor permissions, cohorts, repeatable missions, path versioning, multi-contributor output credits, improved knowledge curation and sensible programme templates. Validate a complete Code Black member journey before expanding the screen inventory.

## Hosted platform readiness

Owner onboarding, verified custom domains, explicit billing/entitlements, tenant quotas, support, operational monitoring, backup/restore drills and independently reviewed security/privacy. Select the commercial/source-licensing strategy intentionally before substantial third-party application-code reuse.

## Preserved long-term direction, not current build scope

Contribution graph; consent-based portable proof/profile; mentoring and teaching; apprenticeships, alumni, rituals and leadership succession; outcome-based community reporting; AI-assisted human coordination. Marketplace, funding, talent discovery, complex credentials, automatic health analysis and sophisticated progression remain deferred.

The 86-screen research inventory is a catalogue of possibilities, not a release obligation. Every new feature should serve people, purpose, progress, projects or proof while keeping participation human.
