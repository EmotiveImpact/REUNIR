# Next production milestones

## Alpha 01: delivered locally

Member community/learning/doing loop, real auth/API/database implementation, scoped rules, frontend preview and recorded tests. Cloud setup remains separate.

## Alpha 02: closed pilot

Connect dedicated Neon/Vercel staging, create the owner's empty Code Black tenant, verify real auth and pooled RLS, configure email invitations and recovery, add straightforward member administration, replace seed content with approved courses/missions, exercise the deployment with two real pilot accounts. Add CI against Postgres and a normal-origin browser.

## Alpha 03: creator operations

Course editing/reordering, richer lesson authoring, attachments inherited from content permissions, instructor roles, scheduled cohorts and repeatable missions, community moderation lifecycle, export/delete tools and worker-backed delivery.

## Beta: hosted platform

Billing and entitlements, owner onboarding, custom-domain verification, configurable branding, tenant-specific quotas, paginated domain reads, search indexing as needed, backup/restore drills, support and operational observability. Select the business/source licence deliberately before significant upstream application reuse.

The 86-screen research inventory is a long-term product catalogue, not an obligation to ship 86 thin screens before validating the core loop.
