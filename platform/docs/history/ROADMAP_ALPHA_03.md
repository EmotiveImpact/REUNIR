# REUNIR roadmap · after Alpha 03

## Preserve

People + Purpose + Progress + Projects + Proof. Keep the community as the place where transformation happens, not a forced consumption feed. Keep purpose-led Home, optional Become/Build/Achieve directions, existing discussions, private goals, evidenced paths, contribution review and outputs. Do not automate permission roles from activity points.

## Delivered foundation

Alpha 01: community, learning, missions, projects, events, notifications, search and moderation on a tenant-aware React/Hono/PostgreSQL foundation.

Alpha 02: purposes, paths, evidence-backed milestones, private member goals, contributions, reviewed outcomes, community output archive and proof-oriented profiles.

Alpha 03: personal invitation account creation, password recovery, encrypted durable email queue, participant-private one-to-one messages, pagination/read markers/idempotency, blocking and selected-message reports, role/private-space management and reversible suspension.

## Next gate: connect, verify and operate the pilot

Import the complete handed-over source into a reviewed GitHub branch and run real application CI. Bind the intended Neon project, rehearse migrations and runtime grants, provision a real owner and set up Vercel staging with live mode. Configure a verified email sender and recurring queue delivery. Complete hosted-browser account tests, two-person/two-tenant privacy checks, monitoring and backup/restore. No arbitrary existing database should be repurposed.

The connected browser script is supplied but was blocked by the sandbox's Chromium navigation policy. Finish that test on staging; do not treat an in-memory UI demo or successful Node HTTP smoke as identical evidence.

## After the pilot is operable

Prioritise general email verification and privileged MFA; export/deletion and retention; moderator escalation/appeals; page-level database pagination beyond messaging; private attachment completion; notification delivery/preferences; richer course editing/reordering; reviewed-evidence revocation/history. Observe actual use before increasing services or feature scope.

## Later, not current implementation

Group chat/live rooms, paid memberships, cross-community portable identity, contribution graph, multi-contributor credits, apprenticeships, curriculum/knowledge versions, alumni and leadership succession. Then AI that connects people to useful work and help, not a compulsory chatbot. Marketplace, funding, AI matching and sophisticated credentials remain deliberately deferred.
