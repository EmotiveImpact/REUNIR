# Approved reference versus integrated application

Source target: REUNIR-shadcn-reference-v4.html and its supplied desktop screenshot. Actual final screenshots are under evidence/alpha07 in the delivery package.

Observed against the reference: the far-left rail is restored, the second sidebar is navigation only, the single header account replaces bottom duplicates, the editorial heading and mountain remain, spacing/borders/buttons are restrained, and people use natural portrait pictures. Mobile capture retains the existing product routes with a focus-cycled drawer and account-menu community switching.

Intentional differences from the static mock: the original app's full navigation remains; role-scoped management is visible only to authorised accounts; Home uses the actual tenant tagline, private member goal, evidence-based progress and real project/member records; community outputs remain available. Mock counts and events are not copied as facts. Existing project thumbnail placeholder art is retained where the app has no image (Alpha 11 later replaced it with uploaded covers and a plain panel; see COVERS.md). No model-generated member testimonial or partnership claim is added.

The supplied reference photo was cropped to remove baked-in side text before using editable purpose links. Existing named portrait fixture images are confined to demo mode. Live members use only their own image or a neutral fallback. Original user images are not recoloured.

Visual inspections used the saved desktop and mobile screenshots of the integrated build, with keyboard, responsive and automated accessibility checks recorded in v4-integration-browser-check.ts. This is an integration review, not a claim of exhaustive pixel identity, audited image rights or complete accessibility certification.
